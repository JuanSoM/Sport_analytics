# TFG template modular

Estructura generada a partir de MAIN_fixed.tex.

- MAIN_base_estable.tex: copia congelada de la versión estable anterior.
- MAIN.tex: archivo principal modular con llamadas a subarchivos.
- sections/: un archivo .tex por sección.
- references.bib: bibliografía inicial preparada.

Los archivos de portada esperados siguen siendo:
- cover.pdf
- title.pdf
- backcover.pdf

Los materiales están marcados en comentarios dentro de cada sección.
